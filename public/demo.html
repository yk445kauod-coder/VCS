Agentic revenue system

This storefront is wired to a live agent.

Everything on this page is the real product. The chat bubble is the embeddable widget running against the live API. The products below come from the same catalogue the agent sells from. Open the chat and try to buy something — it will open an order, pitch an upsell, and take payment instructions.

See the dashboard

Try these, in this order

The agent classifies intent, prices from the catalogue, opens a draft order, then pitches the highest-value upsell. Reply in Arabic and it answers in Arabic.

  1. Ask for a price“How much is the Ethiopia Yirgacheffe?”
  2. Place an order“I want to order two bags of Ethiopian beans”
  3. Accept the upsell“yes” — the subscription is added to the same order
  4. Close it“confirm” — the order moves to pending payment
  5. Switch language“مرحبا” then “أريد أن أشتري القهوة”
  6. Escalate“this is unacceptable, it is late” — routed to a human

What to watch

Every reply in the dashboard carries the decision behind it: the detected intent, the order it opened, and the upsell it offered. 

// POST /webhooks/inbound
{
  "channel": "whatsapp",
  "externalId": "+15550001111",
  "text": "I want to order two bags of
            Ethiopian beans"
}

// → 200
{
  "intent": "order_intent",
  "reply": "Great choice — Ethiopia
     Yirgacheffe 250g is $18.00…",
  "actions": [
    { "kind": "create_order" },
    { "kind": "offer_upsell" }
  ]
}

Put this on your own site

The widget is zero-dependency and renders inside a Shadow DOM, so your CSS cannot break it and it cannot leak styles back into your page. 

<script src="https://your-duty.example/widget/duty-widget.js" async></script>

Or drive it without a browser

Every channel reduces to the same message shape. This is the exact call the steps above make, if you would rather use curl. 

curl -X POST $DUTY_URL/webhooks/inbound \
  -H 'content-type: application/json' \
  -d '{"channel":"whatsapp","externalId":"+15550001111",
       "text":"I want to order two bags of Ethiopian beans"}'
Duty — self-hosted, bring your own database and model. This page is served by the same process as the API, so it is a live integration test, not a mockup.
