## Style Guidelines:

- Primary color: Sky blue (#87CEEB) for a calm and organized feel.
- Background color: Light gray (#F0F8FF), a desaturated tint of the primary color.
- Accent color: Soft lavender (#D8BFD8) for secondary actions.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for headlines or body text
- Simple, clean icons for task categories and actions.
- Clean, minimalist layout with a focus on readability.
- Subtle animations for task completion and updates.
