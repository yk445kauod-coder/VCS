## Hard-won facts (worth keeping)

**Node 24 + `--test test/` fails.** `node --import tsx --test test/` throws
`ERR_UNSUPPORTED_DIR_IMPORT` on ESM. Must use a glob: `node --import tsx --test 'test/**/*.test.ts'`.

**Arabic regexes silently never match.** JS `\b` is ASCII-only, so `/\b(نعم)\b/`
never matches beside Arabic script — no error, just no match. Arabic alternatives
must live in a boundary-free group: `/(نعم|تمام)/u`. This bug was introduced once,
"fixed", and the fix itself silently failed (the python patch didn't match because a
prior edit had changed the line). Verify patches actually landed — assert on the
replacement.

**The storage LIMIT invariant.** In the SQL adapters, `LIMIT` may only be pushed into
the query when *every* `where` key was pushed down; otherwise rows truncate before the
residual JS filter runs and a single-row lookup returns nothing. Guarded by
`hasResidual` in sqlite/postgres/supabase and covered by `test/storage.test.ts`.

**Upsell engine reads the products it is handed.** `findOpportunities({cartProducts})`
does not re-fetch them, so tests must re-read from the catalogue after attaching
upsell rules, otherwise rules look empty.

**Hash-embedding retrieval floor.** A cosine floor of 0.05 on hash embeddings admits
near-noise and pollutes answers with unrelated policies. 0.18 is the working value.

**`node:sqlite` is built in on Node 22+** — the default adapter needs zero native deps.

**Serving port.** The app runs on :8787; the exposed host maps it to :12000.
